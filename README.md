# Authentication & Session Security Simulator

กิจกรรม interactive learning สำหรับรายวิชา 305331/316331 ให้นิสิตสังเกตพฤติกรรม
login/session ตัดสินความเสี่ยงของการเก็บรหัสผ่าน และเลือก control รับมือ brute force
ที่สมดุลกับผู้ใช้จริง ผ่านสามภารกิจรวม 20 สถานการณ์สังเคราะห์

เปิดกิจกรรม: https://panupongsk-cyber.github.io/auth-session-lab/

## Privacy

กิจกรรมนี้ไม่มี backend, analytics หรือการส่งข้อมูลออกจากอุปกรณ์ ความคืบหน้าถูกบันทึก
เฉพาะใน `localStorage` ของเบราว์เซอร์และผู้เรียนสามารถรีเซ็ตได้เอง บุคคล ระบบ และหลักฐาน
ทั้งหมดในกิจกรรมเป็นข้อมูลสังเคราะห์ ไม่มีการ login จริง ไม่มีการถอดรหัส และไม่มีการโจมตี
จริงเกิดขึ้นระหว่างทำกิจกรรม
